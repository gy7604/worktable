# 교대 알람 연동 테스트
Android Studio에서 이 폴더를 Open하고 Gradle 동기화 후 Run할 수 있습니다. JDK 17 / Gradle 8.11.1 / Android SDK 35를 사용합니다.
1. 앱을 열고 '5분 뒤로 맞추기'를 누릅니다.
2. '테스트 알람 등록·켜기'를 눌러 기본 시계에서 테스트 이름의 일회성 알람을 저장합니다.
3. 테스트 앱으로 돌아와 '테스트 알람 취소 요청'을 누릅니다.
4. '시계에서 결과 확인'을 눌러 동일한 이름의 알람이 꺼지거나 삭제됐는지 확인합니다.
아직 일정 자동 연동은 없습니다. 테스트 이름으로만 검색하며 전체 알람이나 다음 알람을 지정하는 취소 동작은 사용하지 않습니다.
삼성 시계의 API 구현이 다를 수 있으므로 기기 테스트가 필요합니다. 요청 성공은 알람 변경 성공을 의미하지 않습니다.
