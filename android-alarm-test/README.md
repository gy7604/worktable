# 교대 기상 알람 테스트 v0.3

본인 교대근무 일정과 연결하는 Android 보조 앱입니다. 삼성 시계 알람과 웹 알림은 수정하지 않습니다.

교대근무 앱 로그인 → 기상 알람 연결 → 연결 코드 발급/복사 → Android 앱에서 붙여넣기/내 계정 연결.

주간/주간 대근 05:00, 야간/야간 대근 17:10 (Asia/Seoul). 휴무 신청은 정규 알람에서 제외합니다. 앱 열기와 JobScheduler 주기 작업에서 31일 계획을 받습니다. 절전/네트워크로 갱신이 늦을 수 있어 급한 변경 후 수동 동기화하세요. 통신 실패는 기존 계획을 유지하며, 인증 해제는 다음 성공적인 서버 확인 시 기상 알람을 중지합니다.

정확한 알람, 알림, 전체 화면 권한을 확인하세요. 알람은 자체 서비스에서 최대10분 반복 소리/진동, 5분 미루기/끄기를 제공합니다. 재부팅/시간 변경 후 저장 계획을 복원합니다. 강제 종료/전원 꺼짐 시 동작하지 않을 수 있습니다. 최신 실기기에서 화면잠금, 재부팅, 절전, 권한 취소를 추가 확인해야 합니다.

연결 코드는256bit 일회용10분, 기기 토큰은 별도 본인 일정 읽기 전용. DB에는 SHA256 해시만 저장하며 private schema + RLS + service-role RPC로 접근합니다. 로그인 코드/세션/서비스키를 APK에 넣지 않습니다. 기기 토큰은 앱 전용 저장소(백업 제외)에 저장합니다.

Actions 빌드는 일회성 debug 서명이라 업데이트 서명 충돌 시 기존 **교대 알람 테스트**만 제거 후 재설치/재연결하세요. 정식 배포 전 별도 안정 서명이 필요합니다.
